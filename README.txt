月台之间 · 互动旅程

打开方式
1. 解压“月台之间-互动网页.zip”。
2. 保持 index.html 和 assets 文件夹在同一目录。
3. 双击 index.html 即可游玩。

场景与操作
- 地图：选择湛江站或临沂站乘车。
- 湛江站：点击右侧“学校”入口，进入学校与男主互动。
- 临沂站：点击右侧箭头前往怜爱的家。
- 怜爱的家：点击鼠标打开动作菜单；点击房间地面，怜爱会走过去。
- 场景页面右上角的地图按钮可返回线路地图，再选择另一站。

扩展方式
地图站点、场景背景图片、地点入口、人物和猫咪动作配置在 assets/world.js。
替换风景时，把图片放进 assets 文件夹，再修改对应场景的 background 路径。
增加场景时，在 scenes 中添加配置；如果它能从地图乘车到达，再加入 map.stops 或车站 hotspots。
需要全新交互行为时，在 assets/game.js 中添加对应的交互处理，再在 world.js 配置可点击对象。
